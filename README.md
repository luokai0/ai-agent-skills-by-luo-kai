### 🐧 Featured collection: Linux System Operations

**1,250 original, distribution-specific skills for AI agents operating 25 well-known Linux systems.** Each distribution has its own folder and 50 independently addressable workflows.

Explore the [Linux System Operations collection](ai-agent-skills/24-linux-system-operations%20%28by%20Luo%20Kai%29/) and its [Linux AI Agent Operating Playbook](ai-agent-skills/24-linux-system-operations%20%28by%20Luo%20Kai%29/LINUX_AGENT_OPERATING_PLAYBOOK.md).

Coverage includes Ubuntu, Debian, Linux Mint, Fedora, Arch, Kali, RHEL, openSUSE, Manjaro, Pop!_OS, Rocky, AlmaLinux, Gentoo, Alpine, elementary OS, Zorin, Parrot, NixOS, Slackware, Void, MX Linux, Tails, Qubes OS, SteamOS, and Garuda.

Every skill now includes a v1.1 agent execution contract: exact task binding, environment preflight, risk classification, task-specific decision points, approval gates, independent verification, stop/recovery conditions, and a privacy-safe handoff. Special safeguards protect Tails privacy, Qubes isolation, NixOS declarative configuration, and SteamOS immutable-system behavior. See the collection’s [skill quality standard](ai-agent-skills/24-linux-system-operations%20%28by%20Luo%20Kai%29/SKILL_QUALITY_STANDARD.md).

Original instructional text and workflow design are authored by Luo Kai. Distribution names and third-party tool names are descriptive references; their respective owners retain their rights.

### 🖥️ Featured collection: Windows Computer Operations

**1,172 task-focused skills for AI agents operating Windows 10 and Windows 11 desktops and laptops, with overlapping workspace, shell, configuration, software, search, archive, storage, network, browser, development, security, accessibility, and recovery workflows consolidated into stronger multi-domain skills.**

Organized around **40 practical domains**, this collection helps agents operate real Windows computers reliably, rather than merely describing which button a person should click. Repeated workflows are being merged into shared skills with explicit domain profiles, preserving the distinct tools, safety boundaries, and verification steps each domain requires.

Explore the [Windows Computer Operations collection](ai-agent-skills/23-windows-computer-operations%20%28by%20Luo%20Kai%29/) and its [Windows AI Agent Operating Playbook](docs/WINDOWS_AGENT_OPERATING_PLAYBOOK.md).

Coverage includes:

- **Desktop interaction:** Start menu, taskbar, windows, File Explorer, keyboard and mouse navigation, UI Automation, accessibility trees, OCR and screenshots.
- **System administration:** Windows settings, users and permissions, processes, services, startup, scheduled tasks, drivers, updates and device management.
- **Command-line operation:** PowerShell, Command Prompt, Windows Terminal, safe scripting, diagnostics and repeatable automation.
- **Files and storage:** Search, metadata, archives, disk usage, removable drives, backup and recovery.
- **Connectivity:** Wi-Fi, Ethernet, DNS, VPN, firewall inspection, browsers and remote desktop.
- **Work and development:** Office workflows, Git, developer tools, WSL, virtual machines, containers and application troubleshooting.
- **Laptop care:** Battery and power management, sleep and hibernation, displays, docks, thermals and peripheral troubleshooting.
- **Security and reliability:** Defender status, privacy, event logs, performance analysis, safe recovery and evidence-based verification.

Each workflow is a `SKILL.md` with stable metadata, prerequisites, Windows-aware procedures, verification, failure recovery, a completion checklist, and a v1.1 agent execution contract tailored to its domain and task. The contract adds target binding, risk classification, task-specific decision points, approval gates, independent verification, stop/recovery conditions, and a privacy-safe handoff. See the [Windows skill quality standard](ai-agent-skills/23-windows-computer-operations%20%28by%20Luo%20Kai%29/SKILL_QUALITY_STANDARD.md). The shared playbook establishes common rules: observe before acting, use least privilege, protect user data and secrets, obtain approval for consequential changes, and verify outcomes instead of assuming a click worked.

## 🚀 Get started

### 1. Clone the repository

Use a recursive clone so the pinned external submodules are included:

```bash
git clone --recurse-submodules https://github.com/luokai0/ai-agent-skills-by-luo-kai.git
cd ai-agent-skills-by-luo-kai
```

If you already cloned it without submodules:

```bash
git submodule update --init --recursive
```

### 2. Find a skill

Browse the collection folders under `ai-agent-skills/`. A skill commonly has a structure like:

```text
skill-folder/
├── SKILL.md          # Instructions and required metadata
├── references/       # Optional supporting documentation
├── scripts/          # Optional helper scripts
└── assets/           # Optional examples and other resources
```

Not every skill contains every optional folder. Check its own instructions and dependencies before using it.

### 3. Install with the Skills CLI

From the cloned repository, install a skill by its registered name:

```bash
npx skills add . --skill agents-md --agent codex --copy --yes
```

Replace `agents-md` with the name of the skill you want and `codex` with an agent supported by the CLI. You can also copy a skill folder into the skills directory used by your preferred agent.

### 4. Use it with your agent

Open the installed skill's `SKILL.md` and follow its instructions. Some skills need additional tools, packages, credentials, or configuration. Review those requirements before running scripts or granting access.

## 🧰 Quality and cross-platform checks

Cross-platform reliability is part of the project, not an afterthought.

The repository's GitHub Actions workflow checks both **Ubuntu** and **Windows**. It currently:
- Runs a static safety and rights audit over the skill collection without executing scripts.
- Scans skill files and bundled assets with ClamAV signatures before publishing a release.
- Keeps original and third-party licensing boundaries documented in LICENSE, THIRD_PARTY_NOTICES.md, and .github/SECURITY.md.

- Checks out the repository and its submodules recursively.
- Enables Git long-path support on Windows.
- Scans tracked paths for Windows-invalid characters, reserved device names, and trailing spaces or dots.
- Validates YAML frontmatter in every discovered `SKILL.md`, including required `name` and `description` fields and duplicate-key detection.
- Checks that skill filenames use the exact `SKILL.md` spelling.
- Runs a real Skills CLI installation from the checked-out repository.

[![Cross-platform compatibility](https://github.com/luokai0/ai-agent-skills-by-luo-kai/actions/workflows/cross-platform.yml/badge.svg?branch=main)](https://github.com/luokai0/ai-agent-skills-by-luo-kai/actions/workflows/cross-platform.yml)

A passing workflow confirms these automated checks for that commit. It does not guarantee that every third-party skill is safe, maintained, compatible with every agent, or free of external dependencies. Review individual skills before use.
