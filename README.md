# Ultron Ultimate Skill

**One integrated AI-agent skill by Luo Kai, consolidating 250 specialist playbooks into a single installable capability.**

This branch contains one skill entry point: [`ultron-ultimate-skill/SKILL.md`](ultron-ultimate-skill/SKILL.md). Its 20 supporting reference modules preserve specialist procedures, technical decision rules, examples, safeguards, verification methods, and failure handling. The former 250 standalone skill directories are not present on this branch.

## What is included

- **1 skill** — `ultron-ultimate-skill`
- **1 entry point** — `ultron-ultimate-skill/SKILL.md`
- **20 progressive-disclosure reference modules** — selectively loaded by domain
- **250 indexed specialist chapters** — all consolidated under the one skill
- **1 shared operating contract** — task interpretation, routing, authority, planning, execution, verification, recovery, and delivery

The reference modules are supporting material for the one skill, not separate skills. This structure keeps the main instructions usable while allowing an agent to load only the specialist knowledge needed for a task.

## Use the skill

1. Open [`ultron-ultimate-skill/SKILL.md`](ultron-ultimate-skill/SKILL.md).
2. Match the task to the capability index.
3. Load the linked reference module and read the exact specialist chapter.
4. Follow the unified authority, execution, verification, and delivery contract in the parent skill.
5. For cross-domain work, load only the additional chapters needed and define clear ownership boundaries.

## Design principles

- Preserve unique technical knowledge; do not reduce specialist procedures to shallow summaries.
- Use one routing and execution contract across domains.
- Keep authorization separate from capability selection.
- Verify outcomes against authoritative evidence.
- Load domain knowledge progressively rather than forcing every chapter into the agent's initial context.
- Keep the repository to one standalone skill; reference files are part of that skill's knowledge package.
